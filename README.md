# Apartment Price Prediction with Python

A learning-oriented Python workflow for cleaning apartment listing data and training a regression-based price estimator.

## What this repository demonstrates

Pandas data wrangling, categorical encoding, scikit-learn pipelines, linear/ridge regression and mean absolute error.

## Source code

Main example: `predicting apartment prices.py`.

## How to explore

Clone or download the repository, open the source file, and review its dependencies and hardware or dataset assumptions. Arduino sketches require the appropriate Arduino IDE board and libraries; Python scripts require the imports and referenced datasets; web exercises can be opened or adapted locally.

## Scope and limitations

This script references external data and the wqet_grader learning dependency. It should be treated as an educational exercise, not a deployed valuation service; no independently verified accuracy is claimed.
